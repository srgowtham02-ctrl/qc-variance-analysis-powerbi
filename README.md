# QC Variance Analysis Dashboard – Power BI

## Project Overview

This project focuses on analyzing and interpreting QC variance
data using Power BI to monitor production quality metrics,
identify variances, and provide actionable insights.

## Objective

- Monitor production quality metrics
- Identify QC variances
- Improve visibility of quality indicators
- Support data-driven decision-making

## Tools Used

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Visualization

## Key Power BI Techniques

- Edit Query
- Advanced Editor
- Merge Queries
- Data Relationships
- Interactive Buttons
- Visualizations

## Project Outcomes

- Improved visibility of QC metrics
- Faster identification of variances
- Reduced manual data-analysis effort
- Supported proactive quality management
